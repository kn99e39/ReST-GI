### Interpretation

This is an actual F/S experiment, not a repeat of WL58's optional-capability admission stop. The dependency-local cache/invalidation algorithm is correct for the tested learned computational model, with positive raw cost savings. The complete physically credible quality-matched benefit is **NOT SUPPORTED** because F itself fails required fidelity. The cause of the shared learned residual is not isolated. Independent reference seed variation is much smaller than the retained directional failure; no new material/reference correction is justified from this batch.
