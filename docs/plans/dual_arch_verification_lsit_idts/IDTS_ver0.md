## 3. Critical contradictions and omissions

**No strict internal contradiction was found in the text.** The issues below are conditional conflicts, omissions, or factual imprecisions.

- **X1. Conditional conflict, B3 vs B4.** B3 says C^t owns visibility and free-space transport affected by edits. If G_psi produces higher-order transport from geometry features without passing each segment through C^t, it owns the visibility of those orders, which contradicts B3. If it does pass through C^t, it reduces to iterated K∘C with a learned correction. B4 defers this, so it is a latent conflict, not a contradiction.
- **X2. Omission, sharp chains vs smooth learned tail.** B1 and B2 put sharpness in K_phi and z^t. B4 allows learned second-order transport. Higher-order transport can be sharp:
  - Two facing near-specular mirrors keep order k in a sharp direction family with weight about ρᵏ. With S1's closure albedo 0.68 at normal incidence (`fixture.json`), orders 3–5 carry 0.46 → 0.21 of order 1 [ARITH].
  - A sharp→sharp→diffuse path (panel → sphere → floor) delivers a spatially concentrated spot to a broad receiver. LPAT shows the reflected spot smeared into a strip in every arm (93B-5, visual only).

  Either the split is by path type, or G_psi carries a sharp-preservation obligation. Neither is stated.
- **X3. Omission, B5 vs B2.** Role-specific states are allowed, but there is no common domain for K_phi. "The same law" is not well defined across two representations whose within-bin statistics differ by role (B-5).
- **X4. Factual precision of the core hypothesis.**
  - (a) ECRO's local operator is geometry-conditioned *by design* (`model86.py:95-107`), so it is not "nominally intrinsic".
  - (b) B2 contrasts IDTS with "a fixed low-dimensional irradiance summary". ECRO's states s and E1 are 64-bin directional states. Its low-dimensional bottleneck is the learned rank-16 projection u = c·s (`model86.py:112`; R = 16), not an irradiance summary. The critique therefore applies to the operator's rank, not to its state.
- **X5. Decision dependency, not an internal contradiction.**
  - If K_phi is a new learned law that replaces frozen ER as the local scattering rule, it conflicts with "Preserve frozen learned ER for local scattering" (`Architecture.md` §1, 2026-11-13). If K_phi is a projection or discretisation of ER, it is consistent.
  - Once the explicit order is fixed, IDTS meets the same owner question that LSIT raised: explicit events 1–2 versus explicit transport kept only as comparators (LSIT plan l.174, l.313).
  - ECRO already contains an explicit state-ray flight with learned local operators (`model86.py:115-119`). So an explicit C^t is within the lineage; the open question is how many events K∘C computes.
- **X6. Curved surfaces.** With patch-level cells, B1 cannot hold exactly for sharp curved materials.
  - A sphere patch spans 45° of azimuth [ARITH: about 0.79 rad × cos(latitude)]. A fixed incident direction is therefore reflected over about 2δn ≈ 1.6 rad depending on which part of the patch is lit, so the effective discretised K depends on source and geometry.
  - Exactness needs δn ≲ α/2. For S2 (α 0.074–0.18) that is about 0.04–0.09 rad, i.e. on the order of 10² sub-cells per current patch, or per-point frames as in EXP's W_ray [ARITH].
  - This conflicts with B1 only under a coarse discretisation, which IDTS does not fix. It is therefore an obligation.

**Conceptual counterexamples (analytic).**
- **Narrow directional source.** Two collimated beams in the same ring-3 bin can differ by up to 0.72 rad in polar angle and produce the same per-bin z. Their reflections differ by about 2Δ, so K_phi(z) is wrong for at least one of them. Measured analogue: identical-encoding beam pairs differ by 0.94 versus noise 0.26 (86A-4, post hoc).
- **Similar binned states.** Let P: L_i → z, and take PL = PL′. For any K_phi and any G_psi restricted to z, the error is at least ½‖K L − K L′‖. For near-specular K this is about ‖L − L′‖ once the redistribution exceeds α. This floor comes from z^t alone, and no learning removes it.
- **g00010 type.** The exact operator through the deployed 16-point encoding misses q by 3.77 versus noise 0.66 (93A-2). ORA's single on g00010 is 0.464 versus T0 0.289 / 0.393 (93C-2), while ORA wins 49/55 and 47/55 of the other geometries.
  - The learned operator hides source-state loss through geometry-specific compensation, which is exactly what IDTS forbids.
  - Consequence: **under IDTS, source-state sufficiency becomes a hard prerequisite**, and its failures appear undiluted. In WL93A this one geometry held 78–88 % of the pooled change (93A-4).
- **Same material, different geometry.** The physical BSDF is identical, yet the learned operator changed 14.5–44 % with a box move (92B-4). A functional invariance test is therefore required, not just frozen parameters.

## 4. Obligations for any future IDTS specification

1. **K_phi signature.** State it as K_phi(material state, incident field in the material frame) → outgoing field. No position, scene, geometry, role or neighbourhood inputs.
2. **Operator class.** It must be able to represent near-specular transport whose effective rank grows with resolution: S1 needs rank 46–59 for 99 % energy even at 64 bins. Low-rank factorisations are excluded for S1/S2-class materials. The class itself remains to be chosen; this is not a design recommendation.
3. **Quantified resolution.** Set angular (and, for point sources and curved receivers, spatio-angular) resolution for every interface that carries sharp information: source state, z^t, K output, C^t transfer and reader lookup, and G_psi if it owns sharp paths. Give an acceptance criterion, e.g. projection error against an un-projected arm, as in WL90 EE.
4. **One state space for both roles.** Define a single state space, basis, unit and frame for source and receiver roles, with a defined projection. Define "physically equivalent incident distributions", and bound the projection error per role.
5. **Physical definition of z^t.** z^t must be computed by C^t from physical sender quantities and be invariant to the receiver's material. No learned encoder, unless its gauge is fixed and tested.
6. **Ownership partition.** Define a written path-set partition between the explicit K∘C iteration and G_psi, by order and/or by path type, that guarantees no double counting. State explicitly whether sharp chains of order ≥ 3 go to K∘C or to a sharp-capable G_psi.
7. **G_psi interface.** State its inputs, and whether every free-space segment it represents is routed through C^t. If it is not, reconcile with B3.
8. **Physical constraints.**
   - K_phi: linearity, non-negativity, passivity and reciprocity (`Architecture.md:38`).
   - G_psi: linearity in emission and zero response.
   - Spectral radius below 1 for the composed operator including G_psi.
9. **Supervision that makes the factors identifiable.**
   - K_phi: material-only or physical stage targets.
   - G_psi: trained on its own path set with K and C frozen.
   - No total-only joint training.
10. **Invariance tests to pass before any fidelity claim.**
    - Same z in different geometries and at different positions gives an identical K output.
    - Swapping the receiver material leaves z^t unchanged.
    - Source use and receiver use agree on equal z.
11. **Curved surfaces.** Use cells or per-point frames whose normal variation is below about α/2 on sharp curved materials, or state that the scope excludes them.
12. **Rigid-edit procedure.** Define which C^t elements, source states and propagated z^t orders are recomputed (full propagation for D_T), the sampling that keeps visibility updates from aliasing, and a measured edit-slope criterion for G_psi on sharp readers.
13. **Relation to ER and to the 2026-11-13 decision.** State whether K_phi is frozen ER or a projection of it, or a new learned law. State how many events are explicit. Obtain an owner decision where this touches "explicit transport as comparators only".
14. **Evaluation.** Use an admitted, never-inspected sharp-reader held-out workload (none exists; see ledger §5.19), with per-geometry reporting so that cases like g00010 cannot dominate pooled metrics unseen.
