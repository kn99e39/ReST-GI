BGC-Transport (a hypothesis proposed for ReST-GI, not an accepted architecture).
  
  Conceptual operator:
    K_scattered(i,j,a,o,c) = d(i,a) * rho(i,a,c) * Z(i,j,a,o,c) / [epsilon + sum_(j',o') Z(i,j',a,o',c)]
  with
    Z(i,j,a,o,c) = sum_r w(i,j,r,c) u(i,j,r,a,c) v(i,j,r,o,c)
  where d(i,a) is the collided incident-energy budget; rho is a bounded predicted total outgoing fraction; w is the pair-conditioned spatial/mixture weight; u is the conditional incoming angular response; v is a normalized outgoing angular distribution. All terms must preserve physical validity. Rank 8 was an initial hypothesis, not an established sufficient representation capacity.
  
  A1. INCIDENT PHYSICS ENCODER: represent source-dependent first-flight behavior using geometric statistics such as collision probability, conditional first-collision mean, conditional first-collision covariance. These are candidate features, not proven sufficient statistics of transport.
  
  A2. BOUNDARY RELATION ENCODER: represent geometry-dependent relationships using source/receiver relative displacement, material-local frames, boundary distances and orientations, source and receiver local boundary context, pairwise geometric context, local material thickness and deformation. Absolute source identity should not be a learned key. However, physically meaningful absolute or material-domain information must not be discarded without justification.
  
  A3. CONDITIONAL ANGULAR-SPATIAL OPERATOR: a shared neural model generates pair-dependent angular and spatial factors. Unlike global ATO, the incoming/outgoing angular factors are not fixed globally for all source/receiver pairs.
  
  A4. ENERGY NORMALIZATION: the assembled scattered operator is nonnegative and bounded by the collided incident-energy budget.
  
  A5. ANGULAR FRAME TRANSFORMATION: the operator should transform consistently with valid source/receiver frame changes. An exact finite-group averaging construction was suggested as a reference mechanism for the verified rest-geometry D4h group. This does not automatically establish continuous rotation or deformation equivariance.
  
  A6. COMPUTATIONAL REPRESENTATION: local sparse pair interactions with a separate representation for long-range transport. One option is to cache compact pair latents and decode angular factors for active illumination queries. Neither its actual cost nor accuracy has been established.
