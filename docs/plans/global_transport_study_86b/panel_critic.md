# CRITIC
## Agreements
- Conclusion. All four proposals select nothing and say the evidence does not yet support selecting a learned global mechanism. All four reviewers accept that statement as an absence-of-evidence statement and reject every stronger reading.
- Exact partitions. b = K(e + C_G b) can be regrouped exactly by segment owner (K/C), by scattering-event count, or lobe-wise, because the frozen ER closure is a sum of non-negative lobes. I confirmed in C:\Projects\ReST-GI\experiments\fnto_compiled82\closure82.py that each term is symmetric in (wi, wo) and that the certificate bounds each component separately. The lobe-wise split is exact only for a fixed per-lobe assignment.
- No single common cause for the four-term K and ECRO failures. All four lenses find the same shared pattern: the outer partition (K vs C; traced <= 2 events vs table) was exclusive, while the learned terms inside it were supervised only on their sum, and a geometry-poor term absorbed what the geometry-specific term under-delivered (K_glob 86 % of the Yellow red mode; ECRO global term +0.017 to +0.064).
- Recursion instability is not shared. It belongs to the recursively composed learned K fitted to a non-passive, path-history-dependent target (rho = gain x return, WL51). ECRO's one-shot operator showed none (flux 0.980-0.998, one geometry and light).
- The ECRO container is not the limit on the WL86 room. A path-traced 1,270 x 64 table through the same readout is at reference noise in the gated classes (E_H 0.0025-0.0032 stationary, 0.0137 in E2 region C). The failure is a level error of a few Lambert patches fed by the sharp panel, exposed by a near-mirror reader.
- A fixed, receiver-side, source-blind ray relation plus a per-bin sender read is the wrong side from which to sample a sharp sender lit by a small source. All four cite the same theory (Veach 8.3; Jensen 1996) and the same WL86A amendment 2 numbers.
- A fixed piecewise-constant direction interface is a fixed-bandwidth mollifier (WL58). Aggregate field error, flux and whole-image error did not predict composed or sharp-reader behaviour (WL42 to WL44/45; WL57-63; WL86 to WL86A).
- ECRO's measured 9x per frame is 5.45x cheaper samples times 1.6-1.7x fewer samples. It is a property of the two-tier estimator at noise-level quality and is not attributable to learning until a physically filled table is measured. I confirmed the factors in C:\Projects\ReST-GI\results\ecro86\results\econ\econ86.json.
- The decisive missing evidence is learning-free. All four name the explicit patch-level transport on ECRO's own state, an accuracy-versus-kernel-time ladder for a path-traced table through the same readout, and an optimised path tracer at matched quality.
- Selective state update has no economic content at the measured state sizes (20.8 vs 28.1 ms wall, 0.057 vs 0.189 ms kernel for 650,240 rays; WL59 1.4-1.7 %).
- On sharp receivers ER's own gap to the physical reference (0.059-0.065) is the size of the WL86 gate (0.06) and of the miss (0.063 / 0.072).
- The hypotheses converge on one construction. Operator H1/H2, information H1/H2, economics H1 and contract H3 are the same design: a lobe-class partition, sharp-lobe events carried by sampling (sender side for the light prefix, traced on the eye side), an explicit broad patch x bin solve, and an optional learned broad tail. Every author rates the learned tail weak and concedes no novelty (classical two-pass rendering; WL84A Track C).
- Reviewers agree on the defects. The learned parts have no demonstrated role; the moderate lobe class (r50 0.15-0.45 rad; 94 % of albedo on the hard population; the WL86 sphere) has no admissible owner; 'CONTRADICTED' for a learned sharp flight overstates a post hoc, single-realisation, marginal test.
- Distinguishing criteria. The lenses give overlapping lists: a separately tallied target per learned term, representability shown by an oracle in the same family before training, per-family reader-importance-weighted scoring against REF-ER with g reported, and a learned term that beats the learning-free operator on the same state.
- Two human decisions are prerequisites: whether a learning-free global solve around frozen ER is a candidate or only a baseline (WL84A X7), and whether multi-view / multi-light / multi-frame workloads are inside GM1.

## Missing considerations
- Path family: glossy-to-glossy higher-order chains. GM1's target is sharp glossy multi-bounce interreflection. In WL86 the failing family is light -> sharp panel -> Lambert patch -> sharp reader, and 89 % of what region C reads comes from Lambert senders. Chains where a sharp reader sees a moderate or sharp sender at table depth are at most about 11 % of that reading. No hypothesis, and no proposed test on the frozen WL86 fixture, exercises the family the milestone is named for.
- Path family: a moving sharp object. Every edit measured so far moves a diffuse occluder or Lambert boxes; the panel and sphere are stationary. No lens asked what becomes edit-dependent when the narrow-lobe surface is the mover. The sender-side deposit, the narrow continuations of the state rays and the class-tagged supervision would then all change together.
- Path family: the limit of very sharp lobes. A sender-side deposit is described as independent of alpha, but the deposit is then read through a sharp reader at patch resolution. That is density estimation seen in a mirror, with a blur of one 25 cm patch. The oracle shows this is acceptable at r50 about 0.15 rad on this room; the closure permits alpha down to 0.004. No lens gave the bias of the deposit-then-read route as a function of lobe width and distance.
- Path family: the light class. The sharp-sender family is hard because the lights are points. GM1's row in C:\Projects\ReST-GI\docs\RESEARCH_ROADMAP.md fixes no light class. With extended lights a receiver-side gather sees the lobe convolved with the light, and a per-light sender-side pass scales with light count and area. Which side samples the family is therefore partly a workload definition.
- Cost term: the shared geometry-update floor. In the WL86 harness every arm pays about 31 ms wall per edit (path tracer 35-36 ms per edit, of which 31 ms is geometry), against 2.5 ms for the in-place edit in WL85. Fill-cost differences of 1-40 ms between learned, explicit and path-traced tables sit inside that floor at low sample counts. No lens separated it.
- Cost term: fidelity and economics were judged at different quality points. The failing gate is a converged-quality comparison (0.06 against a 4,096-spp render). The economics ladder is at whole-image noise levels 0.10 / 0.05 / 0.03, where the path tracer's own region-C error on E2 is 0.324 / 0.188 / 0.121 (econ86.json), above ECRO's bias floor of about 0.073. The sharp bias only matters at 1,024 spp and above, where path tracing costs seconds per frame. No hypothesis states the quality point at which it claims both fidelity and a saving.
- Cost term: patch layout. WL86 patches are analytic rectangles plus an 8 x 4 sphere grid. None of the cost models includes generating and maintaining a patch x bin layout on arbitrary meshes, or the bias from frames that vary inside a curved patch (the reviewer raised this only for the sphere's M table).
- Cost term: transient versus steady state. The prior-art survey notes that physical caches are cheap per frame (1.5-3.5 ms) but lag 8-64 frames after an edit, and that zero-lag validity is the property a geometry-conditioned operator offers. No lens stated whether the economic target is the first valid frame after an edit, continuous motion, or steady state.
- Comparator: a physically computed low-rank tail. The survey lists matrix row-column sampling (Hasan et al. 2007) and hierarchical low-rank view factors (Potter et al. 2022) as the non-learned counterpart of 'visibility rays in, low-rank factors out'. Every lens compares the learned tail with explicit iteration only.
- Comparator: published light-side estimators for the caustic family under edits. Real-time ray-traced caustics (Yang and Ouyang 2021, abstract level) recompute the light-side pass every frame, and selective photon tracing (Dmitriev et al. 2002) identifies and re-shoots only invalid photon groups. These are the physical comparators for the sender-side deposit that four hypotheses rely on, and none of the lenses cites them.
- Comparator: not updating the table. A stale table with a freshly traced low-order part is within 0.87-1.6x of the updated learned table outside region A and E1's panel, at zero update cost. The lenses use the stale arm as a fidelity control only. As an economic baseline it has the precedent of WL57/59, where the stale exact K beat every learned K.
- Comparator and contract clause: online-adapted caches. Neural radiance caches (NRC, NIRC) are the one published learned global family that survives arbitrary edits. They do it by fitting to post-edit path-traced samples, which GM1 excludes ('No T1 supervision/oracle at runtime'). No lens noted that this clause removes that family from the candidate set while leaving it as a comparator a reviewer would ask for.
- Contract clause: no rescue after a result. AGENTS.md says not to switch architecture families or rescue a negative result, and the roadmap freezes gates and scenes before primary results. The convergent hypothesis keeps ECRO's passing part and moves the family WL86A identified to physics, with a class boundary next to the failing panel's r50 (0.146 rad, against the WL85 sharp / moderate boundary 0.15). E1 and E2 have both been inspected. No lens says how such a hypothesis could be posed prospectively.
- Contract clause: ER stays frozen. Architecture.md section 3 requires a separately justified hypothesis for any modification of ER. Information H2's optional footprint-prefiltered compile of ER is such a modification and is not flagged as one.
- Contract clause: two meanings of 'selective'. AGENTS.md defines selective recomputation as rebuilding the complete owned learned state of invalidated units, with geometry-dirty and transport-dirty sets and unit-level preservation reporting. Architecture section 6 defines F/S as same-rule state rebuilds. Under every surviving hypothesis no learned state is invalidated by a rigid edit: it is either absent or regenerated whole. No lens states under which definition a result would be reported.
- Contract clause: baseline roles. The binding terminology gate requires each comparison to state the actual invalidation, native behaviour, T1 quality, rebuild lifecycle and a separate path-traced reference. The proposed tests use 'frozen ECRO checkpoints' as a comparator without a role. Inside the trained room family that is Native Reuse, and no Neural Full Recompute arm exists for a retrained generator. Only the contract lens mentions the roles, and only as a gap.
- Milestone implication, GM2. The lobe-class partition assumes a pointwise K that is a lobe mixture. For a nonlocal K the exit point differs from the entry point, so 'broad / narrow' would also have to classify spatial spread, and the per-material bin matrix becomes a coupling between patches. Transmissive chains put sharp vertices on both sides of a diffuse one, a family neither side samples well. Only the contract lens discusses GM2, and only for ECRO.
- Milestone implication, GM3. The topic document requires a rigid-first design to state its implications for deformation, bending and self-contact. The operator, information and economics lenses do not. A tail generator trained on rigid box poses, class-tagged supervision and object-frame patch layouts all have unstated behaviour under a non-rigid edit.
- Prior-art precedent: antiradiance (Dachsbacher et al. 2007, read in full by the survey). It makes pairwise links independent of third-party occluders, so only links touching the mover change. The price is that occlusion is reproduced by cancellation at the angular basis resolution, the unoccluded operator can create energy, and eigenvalues above one were observed for sharp BRDFs. This is the published form of a visibility-free term, and of the edit locality the operator lens says a resolvent cannot have. No proposal uses it.
- Prior-art precedent: importance-driven refinement (Smits et al. 1992; Christensen et al. 1996). The camera is an admissible runtime input. Every hypothesis assumes a reader-independent state and therefore needs accuracy patch by patch wherever a sharp surface can see. Classical glossy finite-element methods were affordable only because refinement followed a specific light and view. No lens considered importance-conditioned allocation of rays, patches or bins.
- Unexamined class: a learned quantity used only as a sampling density. The survey states that for sharp transport the published economic lever is sampling, not storage (path guiding, ReSTIR PT), because a wrong learned value then becomes variance. The lenses mention this in one clause, or as a control variate, which the information lens shows returns about 1.2x. No lens examined a geometry-conditioned proposal for the sharp connection, or said whether the project invariant 'learned transport response' excludes it.

- [end-to-end economics] Rendered-error-versus-uncontended-kernel-time ladders on the WL86 room for a path-traced table through the same readout (16 to 4,096 spp) and for a path tracer with Russian roulette, at the g-anchored level, scored in region C as well as on stationary pixels. -> Whether any stored-table mechanism, learned or explicit, has economic room, and where the learned fill sits on a common cost axis. If the optimised path tracer reaches the target quality at comparable cost, every two-tier hypothesis falls together.
- [information sufficiency] The WL86A state-relation test (RAY and BIN) repeated with at least 8 independent ray sets and on a never-inspected edit, with uncertainty on RAY. -> Whether a receiver-side fixed relation is structurally biased for the sharp-sender family or only under-budgeted. That decides whether the partition has to change, or whether a denser state inside the unchanged ECRO partition is an admissible reading of the failure.
- [operator representability] Rank and non-negative rank of the 64 x 64 bin-projected ER matrices of panel, sphere and floor, and the composition error of a 64-outgoing-bin interface versus lobe width and incidence, computed on the actual closures. -> The capacity half of the WL86A attribution (R = 16), without training. It also fixes where a broad / narrow class boundary can sit, and therefore how much energy any stored core can own (Lambert-slot share 0.20 / 0.04 versus broad share 0.50 / 0.04).
- [information sufficiency and dynamic response] Lobe-word-tagged shares of radiance and of the T1 - T0 change (light-side narrow prefix; broad -> narrow -> broad links; first broad flight; broad tail; narrow-to-narrow chains), on WL86 and on a workload that qualifies as sharp glossy interreflection, including hard-population materials. -> Whether a broad-core term owns anything above the ER gap; whether the tail contains sharp-mediated links that need visibility; whether glossy-to-glossy higher-order chains are present at all in the evidence base for GM1.
- [learned generalisation, with identifiability separated from operator r] ECRO retrained with one factor changed at a time: term-wise targets from the tagged reference, supervised sender radiance Bq, importance-weighted loss, denser state, larger R, cleaner targets. -> Whether the sharp failure is a property of the partition or of the training recipe, and whether the global term still compensates once each term has its own target. Whether this is admissible under the no-rescue rule is a human decision.
- [operator representability] Oracle-table error under the mirror readout decomposed by sender class, plus an oracle on a configuration where the sharp reader mainly sees moderate or sharp ER senders, or where the sharp surface is the mover. -> Whether a patch x 64-bin terminal table is adequate for GM1's target family or only for Lambert senders. If it is not, every table-based hypothesis, learned or explicit, misses the milestone's subject.
- [dynamic response and end-to-end economics] A workload where the stale control fails in a broad class and the higher-order share is large (for example a closed high-albedo glossy enclosure): ER gap g, cold path-tracing cost, path length, and the tail's edit response against g. -> Whether a geometry-conditioned learned response is testable at all, and whether reuse of any kind has room. Both are currently bounded by an open, direct-light-dominated fixture (84.7 % one-event radiance; 2.4 segments per path).
- [end-to-end economics] Kernel GPU time of ECRO's generator and application, their scaling at 10-100x patches (dense N x N message passing), and the same for explicit sweeps and a physically computed low-rank tail (row-column sampling). -> Whether a learned generator can win on scaling or on accuracy per unit of state. This is the only form in which a learning-specific saving in global transport could appear.
- [information sufficiency] Variance of each class target among inputs with identical 64-bin encodings, for cone, narrow-beam and extended sources, with enough samples to have power. The existing beam test had truth noise 0.40-0.80. -> Whether a source-independent operator on this encoding is admissible beyond point lights. LSPOT already gives stationary E_H 0.026 / 0.035 against 0.004-0.006.
- [dynamic response] The region-C change slopes (0.36-0.63, stored and ungated) decomposed by path family. -> Whether the dynamic failure on sharp receivers is the same family as the static one. If it is a different family, a fix of the static family does not address GM1's edit-response requirement.
- [operator representability, then learned generalisation] For the K side: an oracle fit of a source-independent, geometry-conditioned first-exit family at sources away from every fitted source, with a low-noise first-flight term; and the cost and bias of a learning-free K operator on the same fixture. -> Whether 'learning belongs in K' has learned content beyond the existing pointwise closure, and whether economics H3's regime (K construction 175-380 s) is real or empty.
- [end-to-end economics] External comparators on any GM1 workload: warm path-traced re-rendering (ReSTIR PT class), an online radiance cache with its lag, and the retraining lifecycle of a family-trained generator. -> Whether a lifecycle advantage can be claimed at GM4, and which baseline role a learned generator's retraining occupies.
## Defensible
Four positions survive the reviews, none of them as a selected architecture.

1. **The partition identity, as a constraint.** Splitting ER lobe-wise into a broad and a narrow set gives an exact, exclusive partition of path space: light-side narrow prefix, broad core, eye-side narrow suffix. Both reviewers who checked the algebra confirm it for a fixed per-lobe assignment. It is not an architecture, and its use as the explanation of WL86A is weakened, because the binned receiver-side relation still delivers 74-84 % of the family where the learned flight delivers 1-18 %.

2. **The null with a construction** (operator H2, information H2, economics H1, and contract H1 at GM1). Explicit transport on the same state with nothing learned globally survives as the null hypothesis and as the missing comparator. All four reviewers mark it weakened as an architecture:
   - it has no learned object, and its admissibility as a candidate is an open owner decision;
   - two of its three variants are already measured to miss the sharp family at patch level;
   - its cost and broad-region accuracy are unmeasured;
   - contract H1 in particular is the project's REF-ER reference level, which the GM1 row says does not complete the milestone.

3. **A learned broad tail** (operator H1, information H1, contract H3; the same hypothesis three times). It is not refuted by any measurement. Two reviewers rate it weakened and one refuted, on the same objections:
   - as written, the tail's formula contains sharp-mediated links that its ownership text excludes;
   - its explicit counterpart is unmeasured and expected to be cheap;
   - its owned class is small on moderate-lobe materials;
   - a stale table nearly ties in the class it would own.

   It stays conditionally defensible only after re-specification, and only as a closure for coarse-basis projection error.

4. **ECRO's operator form unchanged, with the recipe at fault.** No lens advocated this, but the reviewers' own evidence leaves it standing: the cause of the missing flight is un-isolated between capacity, loss, optimisation and coverage; the miss is 0.003-0.012 above a gate equal to the ER gap; and no retraining was done. Its frozen-gate verdict is NOT SUPPORTED, and re-opening it is constrained by the no-rescue rule.

Not defensible after review:
- **Operator H3** (defect correction) as a mechanism; its residual identity survives only as an instrument that needs an adequate explicit operator first.
- **Information H3** (control variate): about 1.2x by its own arithmetic.
- **Economics H2** (learned prolongation): no prize shown, and excluded from the sharp family by its own information argument.
- **Economics H3 and the GM2 half of contract H1** (learned nonlocal K): out of GM1 scope, with a uniformly negative transfer record in WL57-80.
- **Contract H2** (enclosure operator): contradicts an explicit contract clause and has no compact form where it would be new.
## No learned global mechanism?
Yes, in its exact wording, and only as an absence statement. Of the three answer types the study allows, it is the only one the evidence carries. It does not extend to 'learned global mechanisms are contradicted' or to 'learning belongs only in the local closure'.

**For the statement**
- Every learned object that touched global transport missed a frozen gate or lost on cost: learned coupling (44 / 672 ms against 5.0 / 11.1 ms, and contact fidelity); ECRO's F2 on the held-out sharp class; no learned K was ever composed with C.
- The one economic result for a learned global object is NOT TESTED by its own protocol. Its 9x is 5.45x cheaper samples times 1.6-1.7x fewer samples, which is the estimator's structure, and no physically filled table was timed.
- The one learned object that met its gates is local (ER), and on sharp receivers its own gap equals the gate.
- Four lenses and four adversarial reviews reach the same sentence independently. The positive hypotheses collapse into one classical construction whose learned part has no demonstrated role.

**Against reading it as more than that**
- The absence is symmetric. The explicit same-state fill, the path-traced-table ladder and an optimised path tracer were never measured, so a learned global operator is neither shown unnecessary nor shown necessary. The claim 'explicit transport would match it for a millisecond' is an operation count, and two of its three variants are already measured to miss the sharp family.
- ECRO's positive results are real and unexplained by any lens:
  - stationary and broad regions at 0.003-0.006 on unseen poses, two edits and two seeds;
  - region-D change slope 0.78-0.95 against 0.46-0.65 for a stale state;
  - a stale state 2.6-3.9x worse in region A and 7-8x on E1's panel;
  - representability shown by the oracle.
- The failure is small and narrow: 0.063 / 0.072 against 0.06, in one region class of one held-out edit, with five candidate causes never varied one at a time.
- The induction 'geometry-conditioned learning fails' rests on three mechanisms trained on one room, one slab and one synthetic family. The induction 'learning works in K' rests on one success, and it misfiles WL57-80, which was a K.
- Two inputs to the conclusion are human decisions, not evidence: whether a learning-free global solve is a candidate or a baseline, and whether multi-view / multi-light workloads are in GM1. Either can change which hypothesis counts as an answer.

**What is contradicted, for the forms tested**
- A dense learned coupling, on cost.
- A recursively composed learned K fitted to a non-passive, history-dependent target.
- Multi-term learned decompositions supervised only on their sum, as a way to get separately meaningful terms.

A learned higher-order response of the ECRO type is not contradicted for broad transport and not shown to be needed.
## Heuristic risk
The survivors carry two different risks. The null is not a decomposition under a new name; it is a classical renderer under a new name, and its risk is being treated as a candidate. The partition-plus-learned-tail hypothesis carries the heuristic-decomposition risk in full.

**Why the lobe-class partition could be another heuristic split**
- **The boundary is a convention drawn around the measured failure.** The lobe sum is exact, but which lobes count as narrow is a threshold. The failing panel straddles it: closure r50 0.146 rad against the WL85 sharp / moderate boundary of 0.15, with 43 % of its albedo sharp and 56 % moderate. A threshold chosen after WL86A, on a fixture whose two edits are both inspected, is fitted to the result in the way distance bands were for FNTO and the event cut was for ECRO.
- **The computational claim is the same kind of smoothness assumption as before.** 'Broad runs fit a 64-bin table and the tail is low rank' has no measurement behind it at 64 outgoing bins. Lobes sharpen toward grazing, so a class fixed at 45 degrees is not a fixed bandwidth class.
- **The unowned class is where the question lives.** Moderate lobes hold a median 94 % of albedo on the hard population and include the WL86 sphere. In the WL85 enabled region the largest indirect contributor to the change is broad-from-moderate (0.28). A partition that is clean only for Lambert-plus-sharp fixtures reproduces the binary diffuse / specular split the prior art says is exact only for binary materials.
- **The learned term's target is defined by the tagging rule.** Class-tagged supervision makes the tail identifiable, but if the threshold moves, the target moves. As written, the tail also contains broad -> narrow -> broad links with no visibility, the form WL86A found geometry-blind.
- **The criteria are retrodictive.** The lenses' checklists (own target per term, oracle first, per-family scoring, beat the same-state operator) were derived from the FNTO and ECRO failures. ECRO passed its own pre-declared contracts as well.

**What would distinguish it from a heuristic decomposition**
1. A class rule fixed in advance from a measured quantity: the composition error of the actual table resolution versus lobe width and incidence. It would be frozen before any result and applied unchanged to a never-inspected edit and to a second material population.
2. Class tallies that sum to the reference, plus a class-swap control: making the narrow lobes absorbing leaves every broad-class output unchanged.
3. A forward prediction that can fail on existing references. The sender-side term alone, with nothing retrained, restores E2 region C to the oracle level per family; switching it off reproduces the WL86A deficit.
4. Representability shown by an oracle in the same family before training, and a learned tail that beats both the explicit sweeps and a physically computed low-rank tail on the same state, in accuracy at equal state or cost at equal accuracy.
