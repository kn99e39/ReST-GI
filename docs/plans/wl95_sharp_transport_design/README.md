## Path note

Paths of the form `C:\Users\...\scratchpad\wl95\<file>.md` inside these files refer to the original session scratch copies. Those files are the ones in this folder; `<file>` maps to `design_<angle>_<kind>.md` for the designer and critic files. Paths of the form `scratchpad\wl95_calc*.py` refer to `results/wl95_calc/`.
